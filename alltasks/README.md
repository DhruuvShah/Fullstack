# React & Node Master Dashboard

This project contains all the tasks from Unit 1 and Unit 2, implemented in React (Frontend) and Node.js (Backend).

## Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

## How to Run the React Frontend Locally

1. **Open your terminal** and navigate to the project directory.
2. **Install the dependencies** by running:
   ```bash
   npm install
   ```
3. **Start the development server** by running:
   ```bash
   npm run dev
   ```
4. **Open your browser** and go to the URL provided in the terminal (usually `http://localhost:5173` or `http://localhost:3000`).

## How to Run the Node.js Backend Scripts

The backend scripts are located in the `backend/` folder. You can run them individually using Node.js.

1. **Open your terminal** and navigate to the project directory.
2. **Run a specific script** by typing `node backend/<filename>.js`. 

Here are the available scripts:

- **File Read Example:**
  ```bash
  node backend/fileRead.js
  ```
- **File Write Example:**
  ```bash
  node backend/fileWrite.js
  ```
- **SetInterval (Append to File):**
  ```bash
  node backend/timeInterval.js
  ```
- **SetInterval (Append Date/Time):**
  ```bash
  node backend/travel.js
  ```
- **OS Module (System Info):**
  ```bash
  node backend/osModule.js
  ```
- **Local HTTP Server:**
  ```bash
  node backend/server.js
  ```
  *(After running, open `http://localhost:8000` in your browser)*
- **User-Defined Module Example:**
  ```bash
  node backend/User_Module.js
  ```
- **String Manipulation Module Example:**
  ```bash
  node backend/app1.js
  ```
- **REPL Calculator Instructions:**
  ```bash
  node backend/repl_calculator.js
  ```
- **Create Student File (5 records):**
  ```bash
  node backend/student_file.js
  ```
- **Faculty HTTP Server:**
  ```bash
  node backend/faculty_server.js
  ```
  *(After running, open `http://localhost:8001` in your browser)*
- **Calculator User-Defined Module:**
  ```bash
  node backend/calc_app.js
  ```
